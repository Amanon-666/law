# 局部历史形状 v1：能训练，但不晋级

2026-11-02。结论只针对本次有限预算下的特征和部署任务，不能写成“历史空间形状无用”。两张图分别告诉我们一个热点在当前位置相对四周强了多少。给同一小网络保留这个差值属于哪一层，比先把差值平均，确实更准地预测了相邻位置的信号差；但定位收益小，在第二栋楼反向。因此不扩大网络、不启动完整 NP、不替换 `refi.py` 或论文主候选。该取舍以定位而非信号拟合为准。

## 哪些没变，唯一改了什么

从 `b7f7dbc` 和已归档的七系数权重 `cd5c4972...` 接续。两组289参数网络完全相同，使用同一训练样本、初始权重、优化步数和后端；均保留原来每个历史来源的六项单点特征、基础 GP 的协方差及漏检模型。新信息只有中心信号减去半个核长度处四个轴向邻点信号均值。EARLY 把两个来源的这一个差值先平均再交给每个来源通道，SEPARATE 保留其对应关系；不是把对照的整张地图或所有单点特征都抹平。新输出只改先验均值，S 在未学习的基础 GP 上定一个全局来源权重，再对各实验臂分别重算标定后验。

冻结后的悉尼模型未经梯度微调直接用于 Tampere 的 TIE1（4个内部目标层）/SAH1（1个）。每层3次相同标定抽取，K=5、R=1；查询排除包含标定的整块区域。五种方法使用相同原始输入权限，近邻的候选是实测指纹，四种 GP 使用相同 H+S 网格。每组最多32个历史可见 AP、每个历史楼层32个区域、每历史区域最多4扫；坐标用历史范围等比缩放，误差还原为米。地理相邻点用于差分监督，监督只比较该热点在两端都至少有两次检出的情形，预测量为检出条件均值，不能外推至稀有或从不检出热点。没有使用 UTS 或 Tampere 官方测试扫描；Tampere 此前已用于开发，非首次揭盲。这里没有用 UJI 的目标查询或 Minho 预留。

## 配对定位误差（米，越小越好）

| 同一预算与查询 | TIE1 | SAH1 |
|---|---:|---:|
| 原始 H+S 的 3-WKNN（本试验预算，不是既定的同图强 WKNN 门槛） | 34.487 | 45.097 |
| 不加学习修正的历史 GP | 19.203 | 35.723 |
| 冻结的七系数基线 | 19.687 | 34.800 |
| EARLY：额外局部对比先平均 | 19.351 | **34.524** |
| SEPARATE：额外局部对比按来源保留 | **19.202** | 34.572 |

相对 EARLY，SEPARATE 在 TIE1 减少0.1485米（0.77%），在 SAH1 增加0.0479米（0.14%）。两栋等权差 −0.0503 米，配对95%区间 [−0.174,+0.070]。每栋区间分别 [−0.330,+0.018] 和 [−0.119,+0.227]。相对七系数，两栋等权减少0.3564米，条件95%区间 [−0.585,−0.150]。这比较包含有无全部局部修正，不能全归给“分别读取历史”。TIE1 上候选比未经学习的 GP 仅好0.001米；两个方法实质相同。SAH1 上候选虽胜七系数，却未胜 EARLY。空间差分 RMSE：TIE1 为4.646→4.628 dB，SAH1 为4.781→4.726 dB（EARLY→SEPARATE）。空间代理指标通过，定位门槛未通过。

聚合方式：按同一精确坐标平均扫描，再等权平均本次查询的空间块、标定抽样、目标楼层。15组均完成；41,706次预测评价实例，固定原始文件中15,677个不同查询行（10,384+5,293），重复标定抽样并不是更多独立环境。每层共同重抽空间块并重抽3个标定种子，固定两栋，5000次，随机种子20261102；不能当作跨新楼的区间。单楼多个层的结果和逐组误差都可用 `verify.py` 得到。TIE1、SAH1 的最低有效采样量分别超过26,149、29,393。P90（EARLY/SEPARATE）分别 39.846/39.310 与 72.416/72.509 米。筛选门槛是两楼分别比 EARLY 和七系数都低至少2%，同时两楼信号差分 RMSE 改善、两楼等权的配对定位区间排除零；没有事后更改阈值、丢弃失败组或选择另一模型。

## 算力、版本和下一件事

UTS源目标楼层为 −2、2、6、11，共2637个可用「邻近区域对×热点」例子，不是2637个独立环境。单线程 CPU 缓存6.82秒；两臂各1000步合计4.72秒（前100步1.26秒），训练进程峰值540 MiB，不含依赖安装和下载。目标端建图与全部比较约319秒（TIE1）/151秒（SAH1），不能写成单个用户查询耗时。冻结构形、数据分块与查询口径均不同于稿件，**不得**与旧稿的 Tampere/SAH1 或 UJI 表 II 数字跨表判胜。本轮不声称跨 K、跨手机、跨期或三个总指标已经通过。

下一步保留现有 GP 和已冻结的七系数/非线性主候选，优先完成既定的原 UJI 每处单扫 K 曲线和留手机比较；不按本次 Tampere 的成绩给各楼分别挑赢家。将来若有不同的关于方向/尺度的机制证据，另行预登记，而不把本次失败扩展成更多网络组件。
